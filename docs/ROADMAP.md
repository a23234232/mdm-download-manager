# 未来改进方向

## P0 · 先把稳定性做扎实

1. **真实网络回归测试**：本地 HTTP 服务器模拟 206/200/断连/限速/ETag 变化，覆盖 1–64 分片、暂停恢复、校验失败。
2. **HLS/DASH 完整度**：直播、备用音轨、EXT-X-MAP BYTERANGE、多 Period、SegmentTemplate 完整继承、`r=-1` 展开、SAMPLE-AES/DRM 明确报错。
3. **FTP/FTPS**：隐式/显式 TLS、目录列表、服务器拒绝 REST 时自动降级、多连接分段。
4. **崩溃恢复**：进程重启后恢复 `downloading` 任务而非一律暂停；对临时文件做长度/ETag 校验。
5. **错误可观测性**：结构化错误码、日志文件、导出诊断包。

## P1 · 体验与生态

6. **浏览器接管增强**：Firefox/Edge 扩展、视频嗅探（m3u8/mpd 自动发现）、POST 下载、批量选择。
7. **任务调度**：定时开始/限速时段、站点规则（按域名设置分片数/代理/限速）、队列优先级。
8. **系统集成**：托盘、开机自启、系统通知点击跳转、剪贴板监听、协议处理器（`mdm://`）。
9. **文件能力**：下载前选择保存位置、完成后自动分类/解压、重复文件检测、磁盘空间预警。
10. **代理**：HTTP/SOCKS5、按任务/全局、PAC。

## P2 · 性能与高级协议

11. **BitTorrent / 磁力**：独立引擎与做种控制；与 HTTP 任务共享队列/限速。
12. **HTTP/2、HTTP/3(QUIC)**、连接复用、服务端限速自适应。
13. **多源下载**：同一文件多镜像并行、按块调度、SHA-256 分块校验。
14. **断点续传增强**：If-Range/ETag 强校验、跨会话恢复、分段级持久化。
15. **流媒体增强**：HLS 直播录制、DASH 字幕/多音轨、封面与元数据、边下边播。

## P3 · 工程化与商业化

16. **自动更新**（Tauri updater + 签名）、崩溃上报（可选、匿名）。
17. **跨平台**：macOS（签名/公证）、Linux（AppImage/deb），统一 CI 矩阵。
18. **测试体系**：Rust 单元/集成测试、Playwright 驱动 WebView、扩展端到端测试。
19. **插件系统**：自定义协议/解析器、脚本化命名规则、Webhook 完成通知。
20. **多语言与无障碍**：英文/日文 UI、键盘导航、屏幕阅读器。
