MDM 下载接管

把 Chrome 下载交给 MDM · 64 分片 · HTTP / FTP / HLS / DASH

连接

在 MDM 桌面端「设置 → Chrome 扩展」中复制 API 地址和令牌。默认端口 45721。

行为

快速开始

  1. 启动 MDM 桌面端，确认标题栏显示「扩展在线」。
  2. 在桌面端打开「设置 → Chrome 扩展」，点「复制令牌」。
  3. 把它粘贴到上方令牌框，测试连接并保存。
  4. 在 Chrome 中点击下载链接，任务会自动出现在 MDM。

如果 MDM 未运行，扩展会放行 Chrome 原生下载，不会丢失文件。快捷键 Alt + Shift + M 可临时切换接管。
